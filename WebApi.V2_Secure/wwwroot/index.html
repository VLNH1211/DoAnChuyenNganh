Bảng Kiểm Tra HTTP Security Headers Chuẩn OWASP
Bản V2 tự động gắn đầy đủ các Header an ninh để phòng thủ chống Clickjacking, MIME-Sniffing và XSS, đạt điểm tối đa trên OWASP ZAP.
Tên HTTP Header Ý Nghĩa Bảo Mật (Mục Đích) Giá Trị Trên V1 (Baseline) Giá Trị Trên V2 (Hardened) Trạng Thái
X-Content-Type-Options Chống MIME-sniffing, buộc trình duyệt tuân thủ MIME type Không có (Thiếu) nosniff ✓ Chuẩn OWASP
X-Frame-Options Chống tấn công Clickjacking / Chèn iframe trái phép Không có (Thiếu) DENY ✓ Chuẩn OWASP
X-XSS-Protection Kích hoạt bộ lọc XSS Filter của trình duyệt Không có (Thiếu) 1; mode=block ✓ Chuẩn OWASP
Referrer-Policy Bảo vệ quyền riêng tư đường dẫn nguồn gốc URL Không có (Thiếu) strict-origin-when-cross-origin ✓ Chuẩn OWASP
Content-Security-Policy Giới hạn nguồn nạp tài nguyên an toàn (CSP) Không có (Thiếu) default-src 'self' 'unsafe-inline' data:; ✓ Chuẩn OWASP
